# 주간 보고 발표본

> 팀원은 **엑셀만** 채우고, 발표본은 여기서 뽑는다.
> **HTML 을 손으로 고치지 마라** — 다음 주에 다시 뽑으면 덮인다. 고칠 것은 항상 엑셀이다.

쓰는 사람이 둘이다. **팀원 = §0**(목요일 퇴근 전, 자기 행만) · **리더 = §1**(금요일, 발표본).

## 0. 팀원 — 비고 칸 채우기

팀원이 이번 주 한 일을 말하면 **엑셀을 대신 열어 고치지 말고**, 그 사람 행의 `비고` 칸에
**통째로 붙여넣을 텍스트 한 덩어리**를 출력한다. 형식은 §3·§4 규격 그대로.

```
다음: 화면설계 착수
이슈: 킥오프 미개최 — 회계팀
09/2주: 화면설계서 3/8 화면 작성
09/1주: ERD 초안 리뷰
```

규칙 4개만 지키면 된다.

1. **지난 주 줄을 그대로 들고 와서 위에 새 줄을 얹는다.** 기존 비고 내용을 먼저 받아라 — 없이 쓰면 히스토리가 날아간다.
2. **주차 라벨은 지어내지 않는다.** `진행현황` 2행의 `주차:` 셀에서 읽는다. 못 읽으면 물어라.
3. **한 줄 = 한 사실.** 「무엇을 어디까지」. 「진행 중」 한 단어는 쓰지 않는다(그게 이 양식을 만든 이유다).
4. 단계 칸이 있는 과제는 끝난 단계를 `[x] 개발 — 홍길동 (09/3주)` 로 바꾼 **단계 칸 텍스트도 같이** 낸다.

⛔ **스크립트로 xlsx 를 쓰지 않는다.** `openpyxl` 은 저장할 때 `x14:dataValidation` 을 조용히 버린다
(`UserWarning: Data Validation extension is not supported and will be removed`) — 한 번 저장하면
드롭다운 7개가 사라진다. 그래서 이 스킬은 **읽기 + 붙여넣을 텍스트 출력**까지만 한다.

## 1. 실행 (리더)

```bash
python "${CLAUDE_PLUGIN_ROOT}/scripts/xlsx2html.py" <엑셀파일.xlsx>
```

같은 폴더에 같은 이름의 `.html` 이 생긴다. 필요한 것 = Python 3 + `openpyxl`.

`openpyxl` 이 없으면:
```bash
pip install openpyxl
```

**엑셀 파일 위치** = 팀이 공유하는 폴더(SharePoint·드라이브 등). 로컬로 내려받아 실행한다.
파일을 못 찾으면 추정하지 말고 경로를 물어라.

실행 후 stdout 을 그대로 사용자에게 보여준다 — 주차·과제 수·이슈 수와 **⚠ 경고**가 여기 찍힌다.
경고는 전부 「예외 없이 조용히 빠지는」 것들이라 **한 줄이라도 뜨면 엑셀을 고치고 다시 뽑는다**(§6 표).

규격을 바꿨으면 `python "${CLAUDE_PLUGIN_ROOT}/scripts/xlsx2html.py" --selftest` 로 파서부터 확인한다
(엑셀 없이 돈다). 여기가 깨지면 발표본이 통째로 틀린다.

## 1-1. 설정 — 팀마다 다른 값은 워크북에 있다

**대부분 이미 있다.** `안내·목록` 시트의 드롭다운 원본을 그대로 읽는다.

| 값 | 어디서 읽나 | 없으면 |
|---|---|---|
| 도메인 목록 | `안내·목록` 의 **「도메인」 칸 아래**(드롭다운 원본 그대로). 빈 칸에서 끊는다 | 오타를 검출할 근거가 없다 + 경고 |
| Jira 주소 | `안내·목록` 의 **「Jira 주소」 칸의 오른쪽 칸** | 티켓 키가 링크 없이 글자로만 + 경고 |

```
      H              I
2   도메인          ...
3   대출
4   컴플라이언스
5   기타            ← 없으면 자동으로 붙는다

      A              B
1   Jira 주소       https://<회사>.atlassian.net/browse/
```

- Jira 주소는 `http://` 또는 `https://` 로 시작해야 한다. 아니면 무시하고 경고를 낸다(발표본을 여는 사람이 있다)
- 둘 다 **없어도 돈다.** 대신 각각 경고가 뜬다 — 설정이 빠진 것도 조용한 실패라 소리를 낸다
- 새 설정 문법을 만들지 않았다. 드롭다운 원본이 이미 그 목록이라 **한 번 더 적게 하면 갈라진다**

## 2. 엑셀 구조 (시트 5개)

| 시트 | 누가 | 언제 |
|---|---|---|
| `안내·목록` | — | 읽기만 (드롭다운 원본 + §1-1 설정 2줄) |
| `진행현황` | 팀원 | **매주** — 자기 행의 상태·비고 |
| `배포이력` | 배포한 사람 | 배포했을 때만 |
| `이슈` | 팀원 | 막혔을 때만 |
| `KPI(월)` | 리더 | 월 1회 (비면 발표본에 절이 안 나온다) |

`진행현황` 9열 = `★ / 도메인 / 과제명 / 담당 / 단계 (체크리스트) / 상태 / Due / 비고 (주간 로그) / Jira`

- **★** — 리더가 지정하는 주요 과제 2~3개. 등급 없음(별 1개만)
- **도메인** — `안내·목록` 의 「도메인」 드롭다운 목록. 목록 밖이면 `기타` 로 접히고 경고가 뜬다
- **담당** — 지금 그 일을 실제로 받는 사람. 두 명이면 `홍길동 / 김철수`
- **상태** — `준비중` / `진행중` / `보류중` / `완료`. 색은 **손으로 찍지 않는다**
- **Due** — `YYYY-MM-DD`. 지났는데 안 끝나면 발표본이 🔴 를 붙인다

## 3. 비고 칸 접두어 3종

발표본의 §완료·§진행 중·§다음 주 계획·§이슈가 **전부 여기서 파생된다.** 따로 적는 시트는 없다.

```
다음: 화면설계 착수                     ← §다음 주 계획
이슈: 킥오프 미개최 — 회계팀            ← §이슈 ('이슈' 시트를 쓰면 그쪽이 우선)
09/2주: 요건 정의서 작성 진행            ← §진행 중 (이번 주 한 일)
09/1주: ERD 초안 리뷰                   ← 지난 주 로그, 지우지 않는다
```

- 한 셀 안에서 `Alt+Enter` 로 줄을 늘린다. **최신이 위.**
- 주차 라벨(`09/2주`)은 `진행현황` 2행의 `주차: 2026년 9월 2주차` 에서 자동으로 계산된다.
  **리더가 매주 그 셀 하나만 고치면** 전체가 따라온다.
- `다음:`·`이슈:` 줄은 비고 열 화면에선 숨긴다 — 각자 자기 절에 나오므로 두 번 보일 필요가 없다.

## 4. 단계 (체크리스트)

**담당이 바뀌는 지점에서만 나눈다.** 같은 사람이 끝까지 하는 일은 **비워 둔다** — 한 줄짜리 체크리스트는 체크리스트가 아니다.

```
[x] 기획 — 홍길동 (09/2주)
[o] 개발 — 김철수
[ ] QA — 이영희
```

`[x]` 끝남 · **`[o]` 지금 이 단계** · `[ ]` 아직. `[o]` 를 쓰면 발표본이 **지금 그 일을 들고 있는 사람**을
현재 담당으로 잡는다 — `[ ]` 첫 줄로만 보면 아직 시작도 안 한 단계의 사람이 담당으로 나온다.

- 끝나면 `[ ]` → `[x]` 로 바꾸고 **끝난 주차를 괄호로** 단다. 그 주차가 이번 주면 §이번 주 완료에 올라간다
- 완료분은 **지우지 않는다** — 누가 언제 무엇을 했는지가 그대로 남는다
- 발표본 상태 칸에 `2/5 · 김철수` 가 자동으로 붙는다 (완료 수 / 전체, 첫 미완료 항목의 담당)
- 에픽 아래로 **행을 늘리지 않는다** — 늘리면 필터·정렬이 깨진다

## 5. 발표본이 뽑는 규칙

| 절 | 소스 |
|---|---|
| 1. 도메인별 진행 현황 | `진행현황` 전 행 (★ 있으면 `1.0 주요 과제` 를 먼저) |
| 2. 이번 주 완료 | 이번 주차가 붙은 `[x]` 항목 + (단계 없는 과제는) 상태 `완료` + 이번 주 로그 |
| 3. 진행 중 | 이번 주 로그가 있는 행의 첫 `[ ]` + 로그 (단계 없으면 로그만) |
| 4. 다음 주 계획 | 비고의 `다음: ` 줄 (없으면 체크리스트 두 번째 `[ ]`) |
| 5. 배포 이력 | `배포이력` 시트 (비면 「이번 주 배포 없음」) |
| 6. 이슈 | `이슈` 시트, 없으면 비고의 `이슈: ` 줄 |
| 7. 월별 KPI | `KPI(월)` 시트 — **비어 있으면 절 자체가 안 나온다** |

색은 **기한 지난 과제에만 🔴**. 🟡(지연 «위험»)은 과제별 진척 데이터가 있어야 재므로 **Jira 연동 후**에 넣는다 — 사람이 손으로 찍으면 전부 초록이 된다.

## 6. 자주 나는 문제

**stdout 경고** — 전부 「고치지 않으면 조용히 빠지는」 것이다.

| 경고 | 무슨 일이 났나 | 고칠 곳 |
|---|---|---|
| `⚠ 주차 미인식` | 2행에서 주차를 못 읽었다 → §완료·§진행 중·§다음 주 계획이 통째로 빈다 | `진행현황` 2행을 `주차: 2026년 9월 3주차` 형태로 |
| `⚠ 이번 주(…) 로그 0건` | 주차는 읽혔는데 그 라벨을 쓴 행이 없다 → 결과는 위와 같다 | 리더가 2행만 다음 주로 고치고 팀원 갱신을 안 받았을 때 나온다 |
| `⚠ 머리말 N행이 비었다` | 그 줄 항목이 발표본 머리말에서 빠진다 | `진행현황` 2·3행 |
| `⚠ 도메인 밖` | 선언 목록 밖이라 **`기타` 표로 접어서** 냈다 | 도메인 칸을 §1-1 「도메인」 목록의 값 중 하나로 |
| `⚠ 상태 밖` | 색·§이번 주 완료 판정이 안 된다 | 상태 칸을 `준비중·진행중·보류중·완료` 중 하나로 |
| `⚠ Due 형식` | 기한이 지나도 🔴 가 안 붙는다 | `YYYY-MM-DD` 로 (`11월 말` 같은 자유 텍스트 금지) |
| `⚠ 도메인 목록 없음` | 도메인 오타를 검출할 근거가 없다 | `안내·목록` 에 「도메인」 칸 (§1-1) |
| `⚠ Jira 주소 없음` | 티켓 키가 링크 없이 글자로만 나온다 | `안내·목록` 에 「Jira 주소」 칸 + 오른쪽 칸 (§1-1) |
| `⚠ Jira 주소 무시` | 주소가 `http(s)://` 로 시작하지 않아 버렸다 | 주소를 `https://` 로 시작하게 |
| `⚠ 담당 불일치` | 단계가 넘어갔는데 담당 칸을 같이 안 바꿨다 | 담당 칸 |
| `⚠ 완료인데 단계가 남았다` | §완료·§진행 중에 같이 나온다 | 단계를 `[x]` 로 바꾸거나 상태를 되돌린다 |

경고가 안 뜨는데 결과가 이상할 때:

| 증상 | 원인 |
|---|---|
| §진행 중에 안 나온다 | 비고에 이번 주차(`09/2주:`) 로그가 없다 |
| §다음 주 계획이 비었다 | `다음: ` 줄이 없다 (진행 중인 일은 여기 안 적는다) |
| 진행률(`2/5`)이 안 뜬다 | 단계 칸이 비었다 — 담당이 안 바뀌는 일이면 정상 |
| 체크리스트가 한 줄만 보인다 | 행 높이가 고정돼 있다 — 행 높이를 자동으로 |

## 7. 안 만든 것 · 안 만드는 이유

| 항목 | 판정 |
|---|---|
| **엑셀 채우기 스킬**(별도) | **안 만든다** — §0 으로 흡수. 쓰기(openpyxl)가 드롭다운을 죽이므로 남는 일은 「텍스트 규격」뿐이고, 그건 이 파일이 이미 SSOT 다 |
| **Jira 업로드 스킬** | **보류** — 어느 프로젝트·필드에 올릴지가 팀마다 다르고, 이미 Jira 자동화를 쓰는 팀과 중복된다. 대상이 정해지면 만든다 |
| **상위 보고용 요약본** | **보류** — 팀 미팅용과 수준이 다르다. 제출처가 정해지면 만든다 |
| 단계 체크리스트 **기본값** | 팀의 태스크·서브태스크 분할 기준(예: 에픽 → 분석·개발·DB·QA·릴리즈)이 정해진 뒤 |
