# 주간 보고 발표본

> 팀원은 **엑셀만** 채우고, 발표본은 여기서 뽑는다.
> **HTML 을 손으로 고치지 마라** — 다음 주에 다시 뽑으면 덮인다. 고칠 것은 항상 엑셀이다.

## 1. 실행

```bash
python "${CLAUDE_PLUGIN_ROOT}/scripts/xlsx2html.py" <주간보고.xlsx>
```

같은 폴더에 같은 이름의 `.html` 이 생긴다. 필요한 것 = Python 3 + `openpyxl`.

```bash
pip install openpyxl
```

파일을 못 찾으면 추정하지 말고 경로를 물어라. 실행 후 stdout 을 그대로 사용자에게 보여준다 —
주차·과제 수·이슈 수와 **담당 불일치 경고**가 여기 찍힌다.

## 2. 엑셀 구조 (시트 5개)

| 시트 | 누가 | 언제 |
|---|---|---|
| `안내·목록` | — | 읽기만 (드롭다운 원본 + 설정) |
| `진행현황` | 팀원 | **매주** — 자기 행의 상태·비고 |
| `배포이력` | 배포한 사람 | 배포했을 때만 |
| `이슈` | 팀원 | 막혔을 때만 |
| `KPI(월)` | 리더 | 월 1회 (비면 발표본에 절이 안 나온다) |

`진행현황` 9열 = `★ / 도메인 / 과제명 / 담당 / 단계 (체크리스트) / 상태 / Due / 비고 (주간 로그) / Jira`

- 1행 = 제목, 2·3행 = 머리말(주차·구성원) — **발표본이 이 3줄을 그대로 쓴다**
- 6행 = 헤더, 7행 = 예시(발표본에서 제외), 8행부터 데이터
- 주차 라벨은 2행의 `… N월 M주차 …` 에서 자동 계산(`09/2주`). **리더가 매주 그 셀 하나만** 고친다
- **★** — 리더가 지정하는 주요 과제 2~3개. 등급 없음(별 1개만)
- **담당** — 지금 그 일을 실제로 받는 사람. 두 명이면 `A / B`
- **Due** — `YYYY-MM-DD`. 지났는데 안 끝나면 발표본이 🔴 를 붙인다

## 3. 팀 고유값은 워크북에 둔다

코드에 팀 이름·도메인·Jira 주소를 넣지 않는다. `안내·목록` 시트에서 읽는다.

| 무엇 | 어디 | 없으면 |
|---|---|---|
| 도메인 목록 | `도메인` 헤더 아래 칸들 (드롭다운 원본 그대로) | `기타` 하나만 |
| Jira 주소 | `Jira 주소` 라벨 칸의 **오른쪽** 칸 (예: `https://<회사>.atlassian.net/browse/`) | 링크 없이 티켓 키만 |
| 팀·주차 | `진행현황` 1~3행 | 기본 제목 |

## 4. 비고 칸 접두어 3종

발표본의 §완료·§진행 중·§다음 주 계획·§이슈가 **전부 여기서 파생된다.** 따로 적는 시트는 없다.

```
다음: 화면설계 착수                     ← §다음 주 계획
이슈: 킥오프 미개최 — 요청 대상          ← §이슈 ('이슈' 시트를 쓰면 그쪽이 우선)
09/2주: 화면설계서 3/8 화면 작성         ← §진행 중 (이번 주 한 일)
09/1주: ERD 초안 리뷰                   ← 지난 주 로그, 지우지 않는다
```

- 한 셀 안에서 `Alt+Enter` 로 줄을 늘린다. **최신이 위.**
- `다음:`·`이슈:` 줄은 비고 열 화면에선 숨긴다 — 각자 자기 절에 나오므로 두 번 보일 필요가 없다.
- §다음 주 계획은 **이번 주 로그가 있는 행만** 낸다. 갱신을 놓친 행의 지난주 계획이 이번 주 계획인
  척하는 것을 막는다(로그가 신선도 보증 역할).

## 5. 단계 (체크리스트)

**담당이 바뀌는 지점에서만 나눈다.** 같은 사람이 끝까지 하는 일은 **비워 둔다** — 한 줄짜리
체크리스트는 체크리스트가 아니다.

```
[x] 기획 — 담당A (09/2주)
[o] 개발 — 담당B
[ ] QA — 담당C
```

**표시 3종** — `[x]` 끝남 · `[o]` **지금 이 단계** · `[ ]` 아직.
「지금 누구 손에 있나」는 `[o]` 가 있으면 그쪽, 없으면 첫 `[ ]` 이다.

- 끝나면 `[ ]` → `[x]` 로 바꾸고 **끝난 주차를 괄호로** 단다. 그 주차가 이번 주면 §이번 주 완료로
- 완료분은 **지우지 않는다** — 누가 언제 무엇을 했는지가 그대로 남는다
- 발표본 상태 칸에 `2/5 · 담당B` 가 자동으로 붙는다 (완료 수 / 전체, 첫 미완료 항목의 담당)
- 에픽 아래로 **행을 늘리지 않는다** — 늘리면 필터·정렬이 깨진다

## 6. 발표본이 뽑는 규칙

| 절 | 소스 |
|---|---|
| 1. 도메인별 진행 현황 | `진행현황` 전 행 (★ 있으면 `1.0 주요 과제` 를 먼저) |
| 2. 이번 주 완료 | 이번 주차가 붙은 `[x]` 항목 + (단계 없는 과제는) 상태 `완료` + 이번 주 로그 |
| 3. 진행 중 | 이번 주 로그가 있는 행의 첫 `[ ]` + 로그 (단계 없으면 로그만) |
| 4. 다음 주 계획 | 비고의 `다음: ` 줄 — 계획은 사람이 정하는 결정이라 체크리스트에서 뽑지 않는다 |
| 5. 배포 이력 | `배포이력` 시트 (비면 「이번 주 배포 없음」) |
| 6. 이슈 | `이슈` 시트, 없으면 비고의 `이슈: ` 줄 |
| 7. 월별 KPI | `KPI(월)` 시트 — **비어 있으면 절 자체가 안 나온다** |

§2~4 는 §1 표와 같은 행 순서로 나오고, 같은 과제의 여러 항목은 한 줄로 묶인다.
도메인은 과제가 없어도 절을 내고 「이번 주 진행 건 없음」을 찍는다 — 통째로 사라지면 「빠뜨린 건지
없는 건지」를 못 읽는다.

## 7. 색은 계산한다 — 사람이 찍지 않는다

| 색 | 상태 |
|---|---|
| 초록 | 완료 |
| 파랑 | 진행중 |
| 회색 | 준비중 |
| 노랑 | 보류중 |
| **빨강** | **Due 가 지났는데 완료가 아님** — 다른 모든 것을 이긴다 |

Jira 상태 카테고리와 같은 축(To Do 회색 · In Progress 파랑 · Done 초록)이라 나중에 Jira 를 붙여도
그대로 매핑된다.

**지연 «위험»(🟡)은 넣지 않았다.** 재려면 과제별 진척 데이터가 필요한데 지금은 없다. 이슈 등록
여부는 이슈 절이 이미 보여주고 기한 임박은 Due 열이 보여준다 — 색이 할 일이 없다. 손으로 찍게
하면 전부 초록이 된다.

## 8. 자주 나는 문제

| 증상 | 원인 |
|---|---|
| 어떤 과제가 발표본에 아예 없다 | 도메인 값이 `안내·목록` 의 도메인 목록 밖 |
| §진행 중에 안 나온다 | 비고에 이번 주차(`09/2주:`) 로그가 없다 |
| §다음 주 계획이 비었다 | `다음: ` 줄이 없다 (진행 중인 일은 여기 안 적는다) |
| 진행률(`2/5`)이 안 뜬다 | 단계 칸이 비었다 — 담당이 안 바뀌는 일이면 정상 |
| Jira 가 링크가 아니다 | `안내·목록` 에 `Jira 주소` 칸이 없다 |
| `⚠ 담당 불일치` 경고 | 단계가 넘어갔는데 담당 칸을 같이 안 바꿨다 |
| 체크리스트가 한 줄만 보인다 | 엑셀 행 높이가 고정돼 있다 — 자동 높이로 |
