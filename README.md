# weekly-report-toolkit

주간 운영 보고 도구. 팀이 같이 쓰는 **엑셀 한 장**에서 주간 미팅 **발표본 HTML** 을 뽑는다.

엑셀이 원본이고 발표본은 매주 다시 생성한다. HTML 은 손으로 고치지 않는다 —
같은 걸 두 군데 쓰면 갈라지기 때문이다.

## 설치

```
/plugin marketplace add kai-gme/weekly-report-toolkit
/plugin install weekly-report@weekly-report-toolkit
```

그 다음 "주간보고 발표본 뽑아줘" 라고 하면 된다. 스크립트만 쓰려면:

```
python plugins/weekly-report/scripts/xlsx2html.py <주간보고.xlsx>
```

필요한 것 = Python 3 + `openpyxl`.

## 이 도구가 하는 일

`진행현황` 시트의 **비고 칸 하나**에서 발표본의 네 절이 전부 파생된다. 따로 적는 시트가 없다.

```
다음: 화면설계 착수                  → 다음 주 계획
이슈: 킥오프 미개최 — 회계팀          → 이슈
09/2주: 화면설계서 3/8 화면 작성      → 진행 중 (이번 주 한 일)
09/1주: ERD 초안 리뷰                → 지난 주 로그, 지우지 않는다
```

단계 체크리스트는 **담당이 바뀌는 지점에서만** 나눈다. 같은 사람이 끝까지 하는 일은 비워 둔다 —
한 줄짜리 체크리스트는 체크리스트가 아니다.

```
[x] 기획 — 홍길동 (09/2주)     ← 끝남
[o] 개발 — 김철수              ← 지금 이 단계
[ ] QA — 이영희                ← 아직
```

`[o]` 를 쓰면 발표본이 **지금 그 일을 들고 있는 사람**을 현재 담당으로 잡는다.
`[ ]` 첫 줄로만 보면 아직 시작도 안 한 단계의 사람이 담당으로 나온다.

## 설계에서 고집한 것

**신호등을 사람이 찍게 두지 않는다.** 색은 상태 열에서 계산하고, 기한이 지났으면 그게 다른 모든 것을
이긴다. 사람이 찍게 하면 전부 초록이 된다.

**실패는 조용히 온다.** 도메인 오타 한 칸이면 그 행이 표에서 사라지고, 주차 라벨을 한 자리 월로 쓰면
그 행이 전 절에서 증발한다. 전부 예외가 아니라 누락으로 나타나므로, 돌릴 때마다 경고로 소리를 낸다.
**설정이 빠진 것도 경고한다** — 없으면 기능이 빠진 채로 멀쩡히 돌기 때문이다.

**팀마다 다른 값은 코드에 없다 — 그렇다고 새로 적게 하지도 않는다.** 엑셀 `안내·목록` 시트에
이미 있는 것을 읽는다.

```
      H              I                    A              B
2   도메인                            1  Jira 주소      https://<회사>.atlassian.net/browse/
3   대출                                  ↑ 라벨 칸      ↑ 그 오른쪽 칸
4   컴플라이언스
5   기타          ← 없으면 자동으로 붙는다
```

도메인은 드롭다운 원본 열을 그대로 읽는다(헤더 「도메인」 아래, 빈 칸에서 끊는다).
Jira 는 「Jira 주소」 칸의 **오른쪽 칸**. 둘 다 없어도 돌지만 각각 경고가 뜬다.

## 규격

전부 `plugins/weekly-report/skills/weekly-report/SKILL.md` 에 있다. 그게 SSOT 다.

파서를 고쳤으면 먼저 이걸 돌린다(엑셀 없이 돈다):

```
python plugins/weekly-report/scripts/xlsx2html.py --selftest
```
